# pengfeitian.github.io

Personal website of Pengfei Tian, live at https://pengfeitian.github.io.

Built with [Jekyll](https://jekyllrb.com) and the [Beautiful Jekyll](https://beautifuljekyll.com) theme, hosted on GitHub Pages.

## Editing

- Bio and references: `index.html`
- Name, navbar links, social links: `_config.yml`
- Photo: replace `assets/img/people.jpeg`

Commit and push to `main`; the site rebuilds in about a minute.
